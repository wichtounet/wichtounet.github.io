Getting back control of a Jablotron security system

Baptiste Wicht

2026-09-27 07:14

Comments

Source

Today, I want to talk about something quite different: how I got back control of a Jablotron security system.

In the house we bought last year, there was a Jablotron security system. I am not particularly a fan of security system nor do we really need it. However, I am a fan of home automation. And I also dislike waste. Therefore, I wanted to use all this hardware and connect it ideally to Home Assistant. This is expensive hardware that is worth more than 4000 CHF. I was expecting a smooth journey, but I was wrong!

Normally, Jablotron systems connect to the MyJablotron cloud through LAN and also have GSM modules. These two connections were not possible since this system was not online anymore. Indeed the previous owners terminated the contract. The hardware was still working as an alarm system but entirely locally. However, it is possible to access the system through USB. And then there are ways to access it from Home Assistant, through an HACS application. Unfortunately, I did not have the master password, so I could not do anything with it. This makes sense since this is after all a security system.

So, I contacted the security firm that did the installation and requested them to give me the master password they had used. And they refused. Apparently, Jablotron only allows official installers to get the key. So, I proposed them to waive the guarantee and give me the code and they did not agree either. I also contacted several other companies and it was the same. They all could reset the system for me, but none of them were willing to give me the master password. This is unfortunately a case of "buying is not owning" which I hate.

So, I did the reset myself. I reset the full system myself with a jumper (and I obviously triggered the alarm in the process) and got inside, with the default installer code. And then the next blocker in this locked ecosystem appeared: the installer software is not available. Fortunately, I could find it online through a reseller (had to pay 75 EUR for it) and got the software and could finally control the full system. Since the system was fully reset, I had to enroll and configure all devices again myself. It was quite tedious but the process is simple. There is really no need for a professional to do that. I could restore devices, sections and users. I had to change some batteries, but overall, the system was working well. The only disappointing thing is that these devices do not like Eneloop batteries because they have a lower voltage output and lead to a battery alert.

With my system back in my control, I could finally connect it in HA. Since Jablotron is connected through USB to HA, I used the Jablotron 100 HACS integration. It worked quite well and is easy to configure. It takes a while to get readings from all the devices, but this makes sense given the low-power devices. These devices are not made for constant but for alerting. Some of these sensors also have temperature sensors that complete my own sensors quite well. I also used the Alarmo plugin to get cleaner dashboards and integrate external devices in the future.

I understand the need for security. But locking down a system so much that even his owner cannot access is simple anti-consumerism. These companies (Jablotron is not the only one) are doing that to ensure they are the ones that can manage it (and charge for it). This is sad, but it unfortunately getting more and more common in the Tech world. In the end, I was able to resolve the issue, but many Jablotron customers would not go through with such manual DIY work.

I hope this can be useful to someone and I wish it was not necessary to spend so much time to take real ownership of a system I already owned.
